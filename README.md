# 📊 Finance Analytics Dashboard

## 📌 Project Overview

A dynamic Finance Analytics Dashboard developed using **Microsoft Power BI and DAX** to monitor and analyze financial transactions, customer behavior, fees, taxes, and transaction performance across business segments and regions.

The dashboard provides stakeholders with a centralized analytical solution for monitoring KPIs, identifying trends, comparing performance, and supporting data-driven financial decisions.

## 🎯 Business Requirements

The dashboard was designed to address key business requirements including:

- Overall transaction growth and financial performance
- Monthly transaction amount trends
- Successful, failed, and pending transactions
- Customer segment contribution
- State-wise financial performance
- Transaction type performance
- Gender-based customer analysis
- Year-over-Year (YoY) performance
- Fees and tax analysis

## 📊 Key KPIs

- **Total Amount** – Total transaction amount with YoY comparison
- **Total Transactions** – Overall transaction volume
- **Average Transaction Value** – Average amount per transaction
- **Total Fees** – Total fees collected
- **Total Tax** – Total tax generated
